# C API

Nix 提供了一个 C API，其目标是[_成为_](https://github.com/NixOS/nix/milestone/52)一个稳定的 API——目前它还不是。该 API 仍在开发之中。

  - [索引（Index）]

- [稳定化里程碑（Stabilisation Milestone）](https://github.com/NixOS/nix/milestone/52)
- [其他 C API 相关的 PR 与 issue](https://github.com/NixOS/nix/labels/c%20api)
