# Release 1.6.1 (2013-10-28)

这主要是一个修复缺陷的版本。值得关注的变更如下：

  - Nix 1.6 意外改变了字符串中反引号插入路径（antiquoted path）的语义，例如 `"${/foo}/bar"`。本版本恢复到 Nix 1.5.3 的行为。

  - 此前，Nix 会把诸如 `"${expr}"` 这样的表达式直接优化为 *expr*。因此它既不检查 *expr* 能否被强制转换（coerce）为字符串，也不执行这种转换。这意味着 `"${123}"` 求值为 `123`，而 `"${./foo}"` 求值为 `./foo`（尽管 `"${./foo} "` 求值为 `"/nix/store/hash-foo "`）。Nix 现在会检查反引号插入表达式的类型并执行相应的强制转换。

  - Nix 现在会显示未定义变量的确切位置。特别是，此前 `with` 中出现的未定义变量错误*完全*不显示位置信息，因此这一改动让修复此类错误变得容易得多。

  - 未定义变量的处理现在保持一致。此前，`tryEval` 函数能捕获 `with` 内部的未定义变量，却捕获不了外部的。现在 `tryEval` 从不捕获未定义变量。

  - `nix-shell` 中的 Bash 补全现在可以正常工作了。

  - 堆栈跟踪的输出更简洁：它们不再显示对内置函数的调用，并且调用栈上的每个 derivation 只显示一行。

  - 新增内置函数：`builtins.typeOf`，它以字符串形式返回其参数的类型。
