R"(

**Store URL 格式**: `mounted-ssh-ng://[username@]hostname`

实验性 Store 类型，允许完全访问远程机器上的 Nix Store，
并且额外要求该 Store 被挂载到本地文件系统中。

该 Store 的挂载不由 Nix 管理，必须手动管理。
例如，可以用 SSHFS 或 NFS 来完成。

本地文件系统用于优化某些操作。
例如，无需将 Nix 归档序列化并通过 Nix 通道发送，
我们可以直接通过挂载点访问文件系统数据。

本地文件系统还使某些原本无法进行的操作成为可能。
例如，如果持久 GC 根与远程 Store 位于同一文件系统上，就可以创建它们：
远程端会创建必要的符号链接以避免竞态条件。
